# digest-collector

Самостоятельный сервис сборки email-дайджеста и отправки через Unisender.
Границы, конфигурация и запуск описаны в README.md и docs/deployment.md.

- Node.js 24, ES modules, npm. Рабочие зависимости: pg и zod.
- Читать только готовый контракт email-period v1 из digest.newsletter_issue_source_v1; не склеивать дневные выпуски.
- Не добавлять сбор Telegram, AI-генерацию, интерфейс подписки или Next.js.
- Runtime использует отдельные роли чтения источника и записи журнала; владелец базы нужен только мигратору.
- Отправка выключена по умолчанию. Тестовые письма допускаются только на digest@irreplaceable-ai.ru.
- Не повторять неопределённый результат отправки. Не выводить credentials, адреса получателей и тело ответа провайдера в логи.
- npm run check; интеграции требуют отдельную одноразовую БД с именем, заканчивающимся на _test.
- Не изменять production-данные или настройки Unisender при запуске тестов.
