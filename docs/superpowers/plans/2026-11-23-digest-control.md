# Панель рассылки — план реализации

Цель — отдельное приложение для владельца с подготовкой, просмотром, отправкой выбранного выпуска и сверкой доставки. У подготовки и отправки свои таблицы команд в соответствующих рабочих базах. Веб-процесс читает статусы и ставит команды под ограниченными ролями. Даты и ключ кампании совпадают с расписанием.

- [ ] Topic Digest. Добавить миграцию 004, обработчик ручных запросов и отметки связи. Использовать одну процедуру подготовки для плановых и ручных выпусков, валидировать три дня архива, завершать и восстанавливать прерванные команды. Проверить unit и PostgreSQL тесты в репозитории производителя.
- [ ] Club Digest Sender. Добавить миграцию 004, очередь действий и сверку с Classic API. Отправлять пропущенный выпуск под исходным ключом, сериализовать плановую и ручную отправку, проверять повтор при подтверждённом отказе. Покрыть конкуренцию, обрыв сети, статистику и старые записи в тестах.
- [ ] Веб-процесс. Реализовать scripts/control.mjs и src/control/ для входа, чтения состояния обеих баз, предпросмотра и POST-команд. Отделить форму подтверждения, использовать сессионный CSRF и проверять каждую команду на сервере. Доступ к Unisender оставить отправщику.
- [ ] Проверка. Прогнать npm run check, миграции на временных PostgreSQL, проверить интерфейс в браузере. Подготовить инструкции развёртывания, отдельные роли и обе ветки для ревью.
